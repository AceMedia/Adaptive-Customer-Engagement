# Assistant for agents (MCP, Abilities, discovery)

Everything the chat widget can do is also available to AI agents browsing the site, generated by this plugin
for any WordPress site (WooCommerce or not). It switches on with the public chat (assistant enabled, widget
enabled, not admin-only), or on its own with the `agent_surface_enabled` key in the `ai_agent` settings (agents
without the visitor widget), and can be forced on or off with the `ace_ai_agent_surface_enabled` filter.

## Tools

Registered as WordPress Abilities in the `adaptive-customer-engagement` category and served to anonymous
agents through a public MCP server (HTTP transport) when the **MCP Adapter** plugin is active:

| Tool | What it does |
| --- | --- |
| `ask` | A question in plain language. Returns the answer, sources and basket links when a product was chosen. |
| `search` | Live site search, products first on shops. |
| `lookup` | Facts for one page, post or product by ID or URL (price, stock, options, components and choices). |
| `catalogue` | Every published product with capacity, price, stock and link. WooCommerce only. |
| `configure-product` | Turns options or component choices into an exact configuration with price, a one-click `basket_url` and `checkout_url`, or lists what is still missing. WooCommerce only. |
| `leave-details` | Name plus email or phone (optionally company and a message) for the team to follow up. |

The MCP adapter exposes them as `adaptive-customer-engagement-<tool>`. Anonymous sessions run as a locked-down
subscriber (`ace-public-agent`, no application passwords, read-only abilities except `leave-details`).
Tune or extend the list with the `ace_ai_agent_tools` filter.

Endpoint: `/wp-json/adaptive-customer-engagement/mcp` (JSON-RPC 2.0: `initialize`, then `tools/list` and
`tools/call` with the `Mcp-Session-Id` header the adapter returns).

## Discovery

- `/.well-known/mcp.json` — machine-readable declaration (endpoint, tools, plain chat endpoint, llms.txt).
- `/llms.txt` — Markdown site index for agents (lines filterable with `ace_ai_agent_llms_txt_lines`; switch off
  with `ace_ai_agent_serve_llms_txt` when another plugin serves it).
- `robots.txt` gains a comment pointing at both, and every page carries
  `<link rel="alternate" type="application/json" title="MCP server">`.

Both paths are WordPress rewrites. If the server adds trailing slashes with its own rewrite rules, exempt
`/.well-known/` and `/llms.txt` from that rule (as the IEG `.htaccess` does), or they will redirect.

## Basket links

`basket_url` is a normal WooCommerce add-to-cart URL. For Composite Products it carries the full
`wccp_component_selection` / `wccp_variation_id` / `wccp_attribute_*` configuration, so opening it in a
browser (or an agent's browser) adds the configured product and `checkout_url` completes the order.
